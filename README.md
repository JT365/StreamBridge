# StreamBridge
A Front End Utility to push Internet Media Stream to Physical Displays like BeadaPanel or its Alternatives.

## Media Formats
* JPG, BMP, PNG, GIF, TIFF, etc
* MP4, ASF, OGG, FLV, WebM, RMVB, MKV, avi, quicktime, H.263/264/265, MPEG-1, MPEG-2
* RGB in various pack
* YUV in various pack

## Browser supported
Opera/CHROME/EDGE
